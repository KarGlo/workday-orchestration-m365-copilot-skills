# Orchestrate Expression Language: global functions

Source: Workday Developer documentation, Integration Apps > Orchestrate Expression Language (retrieved 2026-10-02).
Format of each entry: name(argument: Type, ...) -> ReturnType, followed by the documented behaviour.
Global functions are called with their qualifier, for example lp.stringParam("Name"); functions without a qualifier are called by name.
Member functions are appended to a value of the given type, for example data.Step.response.stringAtJsonPath("$.id").

  Returns a String Map containing all text-valued key-value pairs from the specified integration map. Entries whose values are reference-typed (non-text) are excluded. Example: given an integration map named "map1" configured with the key/value entries key1_1val1_1key1_2val1_2 , the expression intsys.stringMapIterator("map1") produces the output { "key1_1": "val1_1", "key1_2": "val1_2" } . If the map exists but has no text-valued entries, an empty map is returned. If no map with the given name exists, an exception is thrown. The returned map can be consumed inline (example: .get("key1_1") returns "val1_1" ) or stored in a data context and disposed later.
