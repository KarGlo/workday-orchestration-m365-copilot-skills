# Orchestrate Expression Language: member functions for documents and structured data

Source: Workday Developer documentation, Integration Apps > Orchestrate Expression Language (retrieved 2026-10-02).
Format of each entry: name(argument: Type, ...) -> ReturnType, followed by the documented behaviour.
Global functions are called with their qualifier, for example lp.stringParam("Name"); functions without a qualifier are called by name.
Member functions are appended to a value of the given type, for example data.Step.response.stringAtJsonPath("$.id").

When the armored argument is set to true, the output is ASCII-armored; otherwise the output is raw binary.
- toHex() -> Text

- toString() -> String
  Returns a string representation of a document if its content is a textual type. Examples: Json, CSV. Otherwise returns a brief description of the document and content-type.
- unzip() -> DataIterator
  Returns an iterator of all the files present in the archive as Data types.

## Json (member functions)

- addBooleanValue(name: String, value: Boolean) -> Json
  Returns a new JSON document with an additional field of the specified name containing a corresponding Boolean of the specified value. If the input isn't a JSON Array or a JSON Object, the new field and value aren't added and the document is returned as is.
- addJsonValue(name: String, value: Json) -> Json
  Returns a new JSON document with an additional field of the specified name containing corresponding JSON of the specified value. If the input isn't a JSON Array or a JSON Object, the new field and value aren't added and the document is returned as is.
- addNumberValue(name: String, value: Number) -> Json

- addStringValue(name: String, value: String) -> Json
  Returns a new JSON document with an additional field of the specified name containing a corresponding string of the specified value. If the input isn't a JSON Array or a JSON Object, the new field and value aren't added and the document is returned as is.
- arrayAtJsonPath(path: String) -> Json
  Returns the JSON array at the specified JsonPath, if one exists, in a new JSON document. Throws an exception if there's a value at the path, but it isn't an array.
- arrayAtJsonPathWithDefault(path: String, defaultValue: Json) -> Json
  Returns the JSON array at the specified JSON path, if one exists, in a new JSON document. Otherwise assigns the specified default JSON document. Throws an exception if there's a value at the path, but it isn't an array.
- assertValid() -> Json
  Returns the JSON document itself if it is valid. Otherwise, throws an exception.
- bigDecimalAtJsonPath(path: String) -> BigDecimal
  Returns the value at the specified JSON path as a BigDecimal type if the value exists and is a JSON number or a number in a JSON string. Otherwise, throws an exception.
- booleanAtJsonPath(path: String) -> Boolean
  Returns the value at the specified JsonPath if the value exists and is a boolean. Otherwise throws an exception.
- booleanAtJsonPathWithDefault(path: String, defaultValue: Boolean) -> Boolean
  Returns the boolean value at the specified JsonPath if the value exists or the specified default if it doesn't. Throws an exception if there's a value at the path but it isn't a boolean.
- booleansAtJsonPath(path: String) -> Boolean
  Returns all the boolean values at a specified JsonPath, provided all the matching values are booleans.
- convertToXml() -> Xml
  Converts a JSON document to an XML document. XML namespaces and attributes aren't currently supported. Every JSON field is converted to an XML tag.
- convertToXml1(rootName: string) -> Xml
  Converts a JSON document to an XML document with the specified root name. XML namespaces and attributes aren't currently supported. Every JSON field is converted to an XML tag.
- convertToXml2(rootName: string, floatingArrayName: string) -> Xml
  Converts a JSON document to an XML document with the specified root name and the specifed floating array name. XML namespaces and attributes aren't currently supported. Every JSON field is converted to an XML tag.
- convertToXml3(rootName: string, floatingArrayName: string, floatingObjectName: string) -> Xml
  Converts a JSON document to an XML document with the specified root name, the specifed floating array name, and the specified floating object name. XML namespaces and attributes aren't currently supported. Every JSON field is converted to an XML tag.
- countItemsAtJsonPath(path: String) -> Number
  Returns a count of the number of items that match the specified JsonPath.
- distinct(path: StringType, keyPath: StringType) -> Json
  Returns a collection of distinct JSON values as a JSON array. The collection is selected by the specified path. Uniqueness is tested by selecting a value within each item of the collection using the specified key path.
- flatten() -> Json
  Returns JSON array flattened by 1 level.
- includeCharactersUsingList(inclusionList: StringListType, defaultReplacement: StringType) -> Json
  Returns a JSON file, replacing any characters not present in the inclusion list with the specified replacement. Characters that are on the inclusion list are returned unchanged. JSON control characters are returned unchanged.
- indices(path: String) -> NumberList
  Returns all the array indices that match a specified path if the match is an array element.
- isNullAtJsonPath(path: String) -> Boolean
  Returns true if a Json null exists at the specified JsonPath. Returns false if there's a non-null value at the path or if the path doesn't match anything.
- isValid() -> Boolean
  Returns true if the JSON document is valid.
- isValueAtJsonPath(path: String) -> Boolean
  Returns true if a value exists at the specified JsonPath.

  Returns an iterator of JSON values matching the specified JsonPath as JsonType instances.

  Returns an iterator of JSON values matching the specified JsonPath as JsonType instances, batched into JSON arrays of the specified size.

If a column value for one of the indices doesn't exist, an empty string is used instead.
