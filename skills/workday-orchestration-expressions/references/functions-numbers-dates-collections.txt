# Orchestrate Expression Language: member functions for numbers, dates and collections

Source: Workday Developer documentation, Integration Apps > Orchestrate Expression Language (retrieved 2026-10-02).
Format of each entry: name(argument: Type, ...) -> ReturnType, followed by the documented behaviour.
Global functions are called with their qualifier, for example lp.stringParam("Name"); functions without a qualifier are called by name.
Member functions are appended to a value of the given type, for example data.Step.response.stringAtJsonPath("$.id").

## BigDecimal (member functions)

- divide(divisor: BigDecimal, scale: Number, roundingMode: String) -> BigDecimal
  Returns the value of the BigDecimal divided by the specified divisor, using the specified rounding mode when it's required to generate a result at the given scale. A scale of 3 means 3 digits after the decimal point. The number 1.2345 at scale 2 is 1.23. The value 0.0045 is said to be discarded. There are 7 types of rounding modes, 4 directional, 2 nearest neighbor, and 1 other. The directional rounding modes: UP : Rounds away from zero if there are discarded digits. Examples: 5.811 at scale 1rounds to 5.9. -10.0001 at scale 3 rounds to -10.001. DOWN : Rounds towards zero by truncating the discarded digits. Examples: 12.99 at scale 1rounds to 12.9. -0.54321 at scale 3 rounds to -0.543. CEILING : Rounds towards positive infinity. If the number is positive, behaves like UP . Example: 8.7651 at scale 3 rounds to 8.766. If the number is negative, behaves like DOWN . Example: -3.48 at scale 1 rounds to -3.4. FLOOR : Rounds towards negative infinity. If the number is positive, behaves like DOWN . Example: 45.19 at scale 1rounds to 45.1. If the number is negative, behaves like UP . Example: -9.876 at scale 2rounds to -9.88. The nearest neighbor rounding modes: HALF_UP : Rounds towards the nearest neighbor. Rounds up if the discarded digits are greater than or equal to 5. Examples: 9.153 at scale 2 rounds to 9.15. 99.5 at scale 0 rounds to 100. HALF_DOWN : Rounds towards the nearest neighbor. Rounds up if the discarded digits are greater than 5. Rounds down if the discarded digits are equal to 5. Examples: 16.0851 at scale 3 is 16.086. 17.05 at scale 1 rounds to 17. HALF_EVEN : Rounds to the nearest neighbor. Rounds to the last retained even digit if the discarded digits are equal to 0.5. Examples: 7.135 at scale 2 rounds to 7.14. 17.5 at scale 0 rounds to 18. The other rounding mode: UNNECESSARY : Requires an exact result that doesn't need rounding. Throws an exception if the result isn't exact.
- negate() -> BigDecimal
  Returns the negation of the BigDecimal value.
- power(n: Number) -> BigDecimal
  Returns the value of the BigDecimal raised to the power of the specified number.
- precision() -> Number
  Returns the number of digits in the unscaled BigDecimal value. The precision of a zero value is 1.
- remainder(divisor: BigDecimal) -> BigDecimal
  Returns the value of the remainder when the BigDecimal is divided by the specified divisor.
- scale() -> Number
  Returns the scale of the BigDecimal. If the BigDecimal is zero or positive, the scale is the number of digits to the right of the decimal point. If it's negative, the unscaled value of the number is multiplied by 10 to the power of the negation of the scale.
- toString() -> String
  Returns a string representation of the value.

- getOrElse(key: String, default: ZonedDateTime) -> ZonedDateTime
  Returns the value of the specified key, if one exists. Otherwise returns the specified default.
- isEmpty() -> Boolean
  Returns true if the map is empty.
- keys() -> StringList
  Returns a list of the map's keys.
- put(key: String, value: ZonedDateTime) -> ZonedDateTimeMap
  Returns the map with the specified mapping added.
- putAll(map: ZonedDateTimeMap) -> ZonedDateTimeMap
  Returns the map with all of the specified mappings added.
- remove(key: String) -> ZonedDateTimeMap
  Returns the map with the specified mapping removed.
- size() -> Number
  Returns the number of entries in the map.
- toString() -> String
  Returns a string representation of the value.
- values() -> ZonedDateTimeList
  Returns a list of the values in the map.
